# Java Swing - biblioteca do Java
- Biblioteca gráfica fornecida pela linguagem de programação Java para criar interfaces gráficas de usuário (GUIs)
- Cria aplicativos com uma aparência e comportamento visual atraentes e iterativos
- Faz parte da Java Foundation Classes (JFC) e oferece uma ampla gama de componentes GUI
### Vantagens
- Plataforma independente: funcionam em várias plataformas sem a necessidade de reescrever o código
- Componentes personalizáveis
- Rica variedade de componentes
- Interface responsiva: responsivas e rápidas
- Look anda Feel Consistente: adaptaa aparência da aplicação ao sistema operacional
### Desvantagens
- Aparência e Experiência de Usuário: interfaces criadas podem parecer deslocadas e diferentes das interfaces nativas
- Desempenho
- Falta de recursos modernos
