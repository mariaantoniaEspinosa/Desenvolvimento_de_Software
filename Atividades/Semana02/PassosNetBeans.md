Passo a passo

Copie o link do repositório no GitHub:

Abra o repositório.

Clique no botão verde Code.

Copie a URL HTTPS (ex.: https://github.com/usuario/projeto.git).

No NetBeans:

Vá em Team → Git → Clone...

Cole a URL no campo Repository URL.

Clique em Next.

Escolha onde salvar:

Selecione uma pasta no seu computador (ex.: Documentos/GitHub).

Clique em Next e depois Finish.

Abra o projeto:

O NetBeans normalmente pergunta se deseja abrir o projeto.

Se não aparecer, vá em File → Open Project e selecione a pasta clonada.
